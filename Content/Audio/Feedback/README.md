# 界面、倒计时与胜负音效

六段声音均为本项目原创合成，无外部录音、歌曲采样或人声数数。Source 保留 48 kHz / 16 bit WAV 正式音源，SoundWave 关闭循环并接入 SC_XQPEffects，服从现有音效开关及音量设置。离线生成脚本不参与运行。

| 资源 | 时长 | 设计 |
| --- | --- | --- |
| S_UI_Click | 0.115 秒 | 轻木质敲击，有效按钮点击时播放 |
| S_UI_Select | 0.26 秒 | 柔和玉磬音，下拉选项及开关反馈 |
| S_Battle_Countdown | 0.36 秒 | 短鼓点，开局显示 3、2、1 时分别敲一次，无语音 |
| S_Match_Victory | 4.1 秒 | 上行五声音阶，古筝拨弦与明亮竹笛意向的短乐句 |
| S_Match_Defeat | 4.6 秒 | 下行五声音阶，柔和拨弦与低回箫音意向的短乐句 |
| S_Match_Draw | 2.8 秒 | 中性收束拨弦，平局提示 |

音色使用衰减弦谐波、木/玉共振、鼓膜模态与带呼吸噪声的笛箫模型制作；不是实录乐器或实录声乐。全部音源带平滑首尾，保留余音，无削波。

按钮沿用 Slate 有效点击回调；程序初始化、恢复下拉默认值不播放选择音。公共界面、动态列表条目和嵌套按钮均在原控件树配置声音，不改视觉样式。倒计时由 BattleStartComponent 单点去重，联机校时不会重复敲同一数字，重开重新计数。胜负音由 GameState 的正式终局路径触发，按本机阵营判断；观战和单骑积分挑战不播放个人输赢声，重新查看结算界面不重播。
