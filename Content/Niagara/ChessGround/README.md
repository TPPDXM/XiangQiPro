# 中国纹样棋子特效

正式表现全部保存在 Niagara、Material 和 StaticMesh 资源中。运行时仅由 `UChessMoveEffectsComponent` 提交真实位移、目标顶面、攻击方向及画质参数；不依赖离线制作器或验证入口。

| 棋子 | 移动 | 吃子 | 待机 |
| --- | --- | --- | --- |
| 将／帅 | 古铜祥云持续跟随，落稳后单次九宫印 | 上方王气冲击，真正落稳后九宫印 | 不持续发射 |
| 士／仕 | 实体碎玉护卫、细短玉色剑痕、护体闪点 | 位于最高棋子顶面上方的短促斜剑光、碎玉与命中闪光 | 不持续发射 |
| 象／相 | 实体文书卷轴、官员笏板、少量仪仗戟、朱砂烟流 | 文书与仪仗散开、朱砂余光、沉尘碎屑 | 不持续发射 |
| 兵／卒 | 贴近真实步伐的烟尘、过河后前锋闪光 | 朝吃子方向从右上向左下横斩；刀刃与金白剑气共享曲线 | 不持续发射 |
| 马／傌 | 靛蓝分股疾风、金色鬃线、细碎风粒、立体蹄铁与踏蹄闪点 | 落蹄冲击、靛蓝流云与原有土尘碎块 | 不持续发射 |

完整符印集中用于将帅落子的九宫身份；兵、士、相不使用大面积重复符阵。将帅的云角、九宫与回纹材质直接保存折线距离场，无外部纹理或运行时脚本。

士的吃子主视觉以攻击方和被吃方两枚棋子较高的真实顶面为基准，增加至少 5.5 cm 的剑光净空；冲击缩放大于 1 时同步增加净空。PC 和移动端的斜剑光、命中闪光与玉屑共用 `User.TargetTop`，避免吃子时被悬在上方的攻击棋子遮住。地面余痕仍使用原始 `User.HitLocation`，不随主视觉上移。高度修订通过 160 项实际粒子检查，覆盖两端四档画质、四个斜向吃子方向、普通／放大棋子及叠高目标，包含剑光半宽的下缘净空和自然结束。

相以朝廷官员的文书与仪仗物件表现身份。`SM_CourtScroll` 具有弯曲纸页、双侧纸卷、木轴、铜金轴头和实体墨迹；`SM_CourtHu` 为有厚度的象牙色笏板，带束箍和朱绶；`SM_CourtJi` 有红漆杆、金属戟刃与朱色飘带。三者均为保存的立体静态网格，使用受光材质，不是精灵贴图。高档桌面移动最多同时保留一份卷轴、笏板、仪仗戟；低档和移动端保留卷轴及笏板。物件围绕棋子中轴以约 0.32 rad/s 慢速旋转，一周约 20 秒，并保留轻微倾斜。`SM_CourtPaperLeaf` 使用有厚度的纸叶和实体墨迹制作翻飞纸屑；移动纸叶发射率为桌面 22/秒、移动端 16/秒，再乘画质预算，尺寸扩大到原来的约 1.5 倍。吃子另有少量朱砂火星。物件自然淡出，不长期堆积。

朱砂烟流采用更密的路径采样、纵向重叠烟片和专用柔边材质 `M_ElephantMistTrail`，辅以贴近路径的烟絮，减少节状断裂。PC 和移动端分别保留各自的采样及数量预算。

兵的挥刀坐标以起点到目标的平面向量为前，`Up × Forward` 为右；不是固定屏幕坐标。正向、反向及左右横吃均使用同一轨迹。刀尖从攻击方右上经过目标前方收至左下，剑气只展开刀刃已经走过的部分。主挥刀约 0.27 秒，刀身与剑气约 0.58 秒自然淡出。

朴刀网格的刀柄长轴是局部 Z，刃口位于 +X，刀面法线为 Y。桌面和移动端 `PudaoSwing` 的网格槽均设置局部 `Yaw=-90°`，先将 +X 刃口转向局部 -Y，再叠加原有挥刀四元数，使刃口沿轨迹切线迎向挥动方向，刀面法线垂直挥动平面。此校正只作用于刀身的网格渲染变换，刀柄轴、旋转中心、挥动轨迹与剑气时序仍共用原有定义。

将帅默认颜色为古铜色 `RoyalColor=(0.28,0.125,0.045)`，降低与棋盘木色融合的亮黄色成分。`NS_RoyalMoveTrail` 及移动端版本只保留祥云，不包含九宫发射器；祥云从起步时启用，短暂停顿和吃子竖直下落均保持同一纹样。`NS_RoyalCapture` 保留王气冲击、碎屑与闪光，不提前发射九宫印。

真正落稳后，由独立的 `NS_RoyalLanding`／`NS_RoyalLanding_Mobile` 发射一枚约 0.56 秒的古铜九宫印，并停止移动祥云。普通走子在到达时触发；吃子在上方命中后继续保持祥云，经过悬停、下降，接触棋盘后再触发。单次锁存过滤重复落地和联机通知，取消走子不会补印。棋子静止时不创建待机系统，也不执行特效组件 Tick。

PC 与 `_Mobile` 资源分别保存，均使用 CPU 发射器。四档画质保留关键纹样，降低装饰数量；声音和走子结算继续独立运行。`RoyalColor`、`AdvisorColor`、`EarthColor` 与马的 `TrailColor` 可独立调整。

马蹄铁的几何与材质说明见相邻 Knight 目录。移动版已通过桌面进程模拟与资源编译，真机性能需在 Android 设备上另行评估。

前一轮离屏与真实模拟验证覆盖四方向挥刀及刀刃/剑气同步、实体文书发射、仪仗档位预算、马的历史轨迹，以及蹄铁面绕序和真实光源变化。本轮 80 项联合验证全部通过，覆盖 PC/移动音频界面、真实音频设备的独立增益与静音、配置写盘、相的慢速环绕与纸叶数量、烟流重叠以及将帅无待机特效。验证进程报告 0 error、0 warning。

正式功能不依赖制作或验证入口。本轮临时制作与测试源码、脚本、备份、诊断输出和测试模块已清理；清理后 Win64 Development Editor 与游戏目标均重新编译成功，正式二进制未检出临时验证入口。编辑器已恢复并加载正式模块。
