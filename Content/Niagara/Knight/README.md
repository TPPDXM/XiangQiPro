# 马：立体蹄铁、分股疾风与踏蹄冲击

马的视觉使用靛蓝疾风和少量铜金鬃线，士使用青玉碎片和细短剑痕。马不叠加大面积符印；疾风、细碎风粒、交替踏蹄、起跳落尘共同表现腾跃。

## 立体马蹄铁

`SM_KnightHorseshoe` 保留开口和六个钉槽，弧面具有实际厚度及上下倒角。网格宽约 3.24 cm、厚约 0.46 cm，走子仍以 0.6 倍缩放显示四枚交替蹄铁。已校正面的绕序，使上表面朝外，并与手工倒角法线一致。

三个独立受光材质分别表现铁面、磨亮边缘与深色钉槽。铁面、亮边使用不同的金属度和粗糙度，加入细密拉丝变化；淡出仅连接遮罩，不用自发光替代光照。无反射环境中仍保留足够的铁面明暗层次。切换场景真实方向光后，铁面和倒角的渲染结果会明显改变。

`AirborneHorseshoe` 按真实 `HoofProgress` 依次采样实际顶面位置；已出现的蹄铁锁定世界位置，不整串跟随棋子。四步、左右偏移 0.95 cm、独立约 0.72 秒淡出的节奏保留。

## 疾风与碎光

`NS_KnightMotionTrail` 和 `_Mobile` 版本采样完整 XYZ 位移，历史点抵消当前载体位移，不预画未来轨迹。组件跟随真实棋子网格顶面，避免固定高度把风带埋进棋身。

主风使用靛蓝分股材质，配一条短金色鬃线和细碎风粒。默认线性 `TrailColor=(0.10,0.12,0.48,1)`，与士的青玉色分开。落蹄短闪只在对应步点出现，继承步点的世界位置与自然淡出机制。

## 运行时约束

PC 与移动端分别使用 MoveTrail、MotionTrail、Capture 资源；全部为 CPU 发射器。既有移动预算、吃子预算、对象池租约和真实到达信号继续有效；低档减少装饰数量。音效独立于画面开关，不额外延长走子时间。

蹄铁、文书等正式模型及材质均保存在 Content 中；运行时不依赖临时模型生成脚本或测试入口。移动端已通过桌面进程模拟，尚未进行 Android 真机测试。
